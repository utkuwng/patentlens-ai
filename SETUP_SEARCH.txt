SEARCH TỰ ĐỘNG ỔN ĐỊNH
-----------------------
Google Patents có thể trả HTTP 503 khi bị gọi tự động từ IP datacenter/Cloudflare.
Bản v8 có provider cascade:
1. SERPAPI_KEY (ổn định nhất cho Google Patents)
2. Google Patents direct (không cần key, nhưng có thể bị 503)
3. EPO OPS nếu có credential

Khuyến nghị cho prototype:
Cloudflare → Worker patentlens-ai → Settings → Variables and Secrets
→ Add secret:
Name: SERPAPI_KEY
Value: API key SerpApi của bạn
→ Save / Deploy.

Không đưa API key vào GitHub.

Sau đó /api/health sẽ cho biết provider nào đã cấu hình.
