PATENTLENS v8.2 PRO
===================

SỬA 2 LỖI CHÍNH
1. Query tiếng Việt rác kiểu: "nhất" AND "bằng" AND "cách"
2. Google Patents direct HTTP 503

Bản v8.2:
- lọc stopword tiếng Việt mạnh hơn;
- ưu tiên cụm kỹ thuật từ tiêu đề sáng chế;
- tạo query theo cụm 2–7 từ, không quote từ rác đơn lẻ;
- từ chối chạy search nếu query không đủ ít nhất 2 technical terms;
- thêm Cloudflare Browser Run làm provider tìm kiếm tự động KHÔNG cần SerpApi key;
- provider order:
  SerpApi (nếu có)
  → Cloudflare Browser Run
  → Google direct
  → EPO OPS (nếu có).

CÁCH CẬP NHẬT
-------------
Upload đè 3 file:
- worker.js
- wrangler.jsonc
- package.json

Commit main → Cloudflare auto deploy.

Sau deploy mở:
/api/health

Mong đợi:
"browser_run": true

Ví dụ:
{
  "ok": true,
  "providers": {
    "serpapi": false,
    "browser_run": true,
    "epo_ops": false,
    "google_direct": true
  }
}

Browser Run có free tier trên Cloudflare. Nếu tài khoản/project yêu cầu bật Browser Run,
vào Cloudflare → Compute → Browser Run và hoàn tất enable theo giao diện.

Sau đó vào web:
- upload lại PDF từ đầu;
- kiểm tra Title/Claim;
- tạo lại Dấu hiệu kỹ thuật;
- Bước 4 tạo lại chiến lược;
- Bước 5 bấm "Dùng truy vấn từ bước 4";
- query không còn được phép là các từ chung như "nhất bằng cách".
